# dilfwizard.github.io
<h3>Athanor Beats</h3>
A tone generator for producing binaural, monaural and isochronic beats.
<h3>Great Work Visualizer</h3>
An audio visualizer with the ability to visualize live audio as well as upload audio files. Includes multiple options and FX.
<h3>Alchemy Tuner</h3>
A universal instrument tuner that allows you to easily adjust the tuning pitch (e.g. 432Hz) as well as input custom instruments.
